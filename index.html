07 / EVERYDAY WORK

익숙한 업무를,
자연어로 요청합니다.

거래처 정보 조회부터 정형 보고서 생성, 재고 분석까지. 항목을 선택해 요청 예시와 필요한 데이터, 결과 형태를 확인할 수 있습니다.

01 · 정보 조회

“A 거래처 계약조건 보여줘.”

거래처 정보와 관련 계약서, 담당자 정보를 연결해 필요한 내용을 정리합니다.

연결 데이터
거래처 + 계약서 + 담당자
결과 형태
계약조건 요약 및 원본 확인 경로
검토 포인트
계약 버전과 문서 접근 권한 확인
02 · 회계 조회

“이번 달 미수금 업체 알려줘.”

권한 범위의 회계 데이터를 조회하고 기준 시점에 맞춰 업체별 미수 현황을 정리합니다.

연결 데이터
거래처 + 회계 + 채권 데이터
결과 형태
업체별 미수금 내역과 합계
검토 포인트
조회 기준일 및 원장 합계 대조
03 · 보고서 생성

“지난 2년간 매출을 분석해서
Excel로 만들어줘.”

ERP 매출 데이터를 조회·가공하고 원본과 대조한 뒤 회사의 정해진 보고양식으로 생성합니다.

연결 데이터
매출 + 상품 + 기간별 집계
결과 형태
월별·제품별 분석 Excel
검토 포인트
원본 건수·총합계·월별 합계 일치
04 · 예측 지원

“재고가 부족해질 가능성이
높은 상품을 알려줘.”

판매와 재고 데이터를 분석해 예상 부족 상품을 제시하고 담당자의 판단을 지원합니다.

연결 데이터
판매 이력 + 현재 재고
결과 형태
부족 가능성이 있는 상품과 분석 근거
검토 포인트
예측 가정과 데이터 시점 확인

위 화면은 업무 설계 예시이며 실제 ERP나 AI에 연결된 서비스가 아닙니다. ‘검토 포인트’와 일부 결과 상세는 구현 검토를 위한 보완 제안입니다. 실제 적용은 데이터 정비와 권한·검증 체계 구축 이후 진행합니다.

TRUST & CONTROL

08 / VERIFY FIRST

결과의 신뢰는
원본 대조와 검증에서 시작됩니다.

30만 건의 매출 데이터를 Excel로 만드는 경우에도 숫자는 ERP 원본에서 조회합니다. AI의 설명과 실제 데이터 계산을 구분하고, 결과물의 일치 여부를 확인합니다.

원본 조회

ERP API를 통해 실제 데이터를 가져옵니다. AI가 수치를 임의 생성하지 않습니다.

자동 대조

건수와 총합계, 월별 합계를 ERP 원본과 비교합니다.

권한·감사

업무별 권한과 규칙을 적용하고 실행 이력과 검증 결과를 관리합니다.

원본 조회 건수=Excel 데이터 건수
원본 매출 합계=Excel 매출 합계
원본 월별 합계=결과물 월별 합계
불일치 시
검증 실패결과물 재확인·재처리

운영 보완 제안: 검증 실패 결과는 배포를 보류하고, 데이터 변경·회계 처리 등 중요 작업에는 사람의 승인 절차를 적용합니다. 구체적인 승인 기준은 설계 단계에서 확정합니다.

DEVELOPMENT & PEOPLE

10 / HUMAN-LED, AI-ASSISTED

설계와 책임은 개발자가,
반복 구현은 AI와 함께.

AI Coding은 코드 작성과 문서화를 지원할 수 있습니다. 안정적인 ERP를 위해 업무 프로세스, 데이터 구조, 검증과 운영의 책임은 사람이 맡아야 합니다.
